Open extraction protocol · bring your own key

Search the Pramana knowledge base

Trace a claim back to the numbers it rests on

Pick a topic and this page runs the Pramana extraction pipeline on open papers, using your own model key. Two readers extract each paper independently. Fields they agree on are kept, each with a pointer to the sentence it came from, and you can publish the result as a bundle on Logos Storage.

Start with your own key Pipeline source on GitHub

The data layer holds only what each paper reported. Interpretations live in separate signed lenses. Every record carries a pin: SHA-256 hashes of the schema and prompts, plus the model IDs that produced it.

Demo mode. The design, the two papers and both readers' outputs are pre-recorded, so nothing is sent anywhere and nothing is charged. The comparison, hashing and bundle steps run for real.

01

Keys

Choose a model provider and paste a key. Reader A and reader B should differ in model or temperature so their errors are less likely to coincide.

Provider

The page appends /chat/completions unless the URL already ends with it. The endpoint has to allow requests from a browser (CORS).

Your key goes from this page straight to the provider you chose, and nowhere else. There is no Pramana server in between. Unless you tick the box above, the key lives only in this tab's memory and is gone when you close it.

Design

The design model proposes search queries and topic-specific fields on top of the core claim fields. Review and edit them before anything runs. The pin below changes whenever you do.

Core fields follow the Pramana claim model: an assertion (who said it, the quote) kept apart from the proposition (subject, outcome, measure, relation, direction, magnitude, population, conditions, modality). Add or remove fields under topic_fields.

    06

    Agreement

    The two readings are compared field by field with fixed rules: normalized text match, 1% tolerance on numbers, and a check that every quote actually occurs in the text the readers saw. Disagreements go to a judge model or to you.

    Waiting for extractions.

    07

    Publish

    Each paper becomes a protocol record. The records and a manifest form a bundle, and the bundle's SHA-256 is part of its file name. Download it, add it to Logos Storage from your own node, and paste the content ID back here.
